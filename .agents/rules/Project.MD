# Project Rules

Tech Stack
- Next.js 14+ App Router
- TypeScript Strict
- Tailwind CSS
- Framer Motion
- shadcn/ui

Coding Style
- Gunakan Functional Components
- Jangan gunakan Class Components
- Gunakan TypeScript type, jangan any
- Gunakan Server Components jika memungkinkan
- Semua styling menggunakan Tailwind
- Jangan menggunakan CSS Module
- Gunakan Lucide React untuk icon

Folder Convention
- Semua section di components/sections
- Data statis di folder data/
- Utility di lib/
- Types di types/

Animation
- Gunakan Framer Motion
- Semua transition harus smooth

Responsiveness
- Mobile First 
- Gunakan breakpoint Tailwind

Code Quality
- Jangan hardcode data
- Komponen harus reusable
